Prototype evidence — 4 required components
ISYS3443 Assessment 3 rubric · AI functionality requirements
Rubric
1
Input — customer query via CommBank app chat interface
What the input is: A customer types a natural language financial query into the CommBank AI chat interface.

Example: "How much did I spend on food last month?"

How it's processed: The query is sent via POST request to an n8n Webhook node (POST /pfa/query), which triggers the automation pipeline. AWS Comprehend NLP Classifier extracts intent: spending_query, entity: food, period: last_month.

Screenshot evidence: AI Chat tab → user input field with typed query shown before sending.
2
AI processing — NLP + XGBoost ML + RAG + Claude LLM pipeline
AI technologies used: NLP intent classifier (AWS Comprehend), XGBoost classification model (AWS SageMaker), RAG retrieval layer (Redshift + S3), Claude LLM (AWS Bedrock via Anthropic API).

What happens internally: NLP classifier routes the query → XGBoost fetches and aggregates categorised transaction data from Redshift → RAG layer formats a grounded prompt with real figures → Claude API generates a personalised natural language response → n8n IF node checks confidence score.

Screenshot evidence: n8n Workflow tab shows full node-by-node automation pipeline with trigger/action flow, AI API connections, and IF decision logic — satisfying the automation workflow requirement.
3
Output — RAG-grounded AI response generated by Claude API
Example output: "In April 2026, your total food spend was $1,124 — $187 above your 3-month average of $937. Groceries: $484, Dining out: $640. Top spend: The Grounds, Alexandria ($94)."

Why this is genuine AI: The Anthropic Claude API processes the RAG-formatted prompt and generates a unique, data-grounded natural language response. No response is templated — each is generated by the LLM in real time using real transaction figures injected via RAG.

Screenshot evidence: AI Chat tab → typing indicator → AI response appears with pipeline attribution tag.
4
Business action — ML-triggered alert, dashboard insight, or escalation
Actions triggered by the system:
• Push notification: LSTM model detects upward dining trend (confidence: 91%) → n8n IF node → push alert dispatched to customer's device.
• Dashboard insight: XGBoost recategorises transactions → spending summary and AI insight card updated in real time.
• Agent escalation: If response confidence <70%, n8n routes query to CBA customer service desk — no low-confidence output is ever shown to the customer.

Screenshot evidence: Dashboard tab → red ML-triggered alert bar shows confidence score, trend detection, and business action label.
