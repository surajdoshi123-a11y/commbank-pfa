Prototype evidence — 4 required components
ISYS3443 Assessment 3 rubric · AI functionality requirements
Rubric
1
Input — customer query via CommBank app chat
What: Customer types a natural language financial query into the CommBank AI chat interface.

Example: "How much did I spend on food last month?"

Processing: Sent via POST to n8n Webhook → AWS Comprehend NLP extracts intent: spending_query, entity: food, period: last_month.
2
AI processing — NLP + XGBoost + RAG + Claude LLM
Technologies: NLP (AWS Comprehend), XGBoost (SageMaker), RAG (Redshift + S3), Claude LLM (AWS Bedrock / Anthropic API).

Internally: NLP routes query → XGBoost fetches categorised transactions → RAG formats grounded prompt → Claude generates response → n8n IF node checks confidence and routes output.

Evidence: n8n Workflow tab — full node pipeline with trigger/action flow and IF decision logic.
3
Output — RAG-grounded AI response from Claude API
Example: "In April 2026, your total food spend was $1,124 — $187 above your 3-month average. Groceries: $484, Dining: $640. Top spend: The Grounds, Alexandria ($94)."

Why genuine AI: Claude API generates a unique natural language response from the RAG-formatted prompt in real time. No templating — every response is LLM-generated from real transaction figures.
4
Business action — alert, dashboard update, or escalation
• Push notification: LSTM detects dining trend (91% confidence) → n8n IF node → alert sent to device.
• Dashboard insight: XGBoost recategorises spend → AI insight card updated.
• Escalation: Confidence <70% → n8n routes to CBA service desk agent.

Evidence: Dashboard tab → red ML-triggered alert bar with confidence score and action label.
